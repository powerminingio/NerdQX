# Changelog for NerdQX project
## Revisions

### 1.0.1
* Capacitors increased to a higher nF rated power
* Updated schematics with correct cap rating
* Gerber list re-exported and verified
* Pick & Place list/configuration exported and verified
* BOM updated according to current schematics

### 1.0
* Horizontal PCB geometry and alignment
* New alignment of voltage regulators
* XT60 power connection
* Increase in trace spacing compliance
* Add fiducials for both sides
* Mounting holes for custom VREG coolers implemented
* Add I2C pull-up
* Temperature diode positioned centrally between ASIC processors
* Tmux implemented for direct ASIC measurement
* Additional 4-pin for fan implemented (M3)
* Blade-type fuse holder supporting up to 30A mini automotive fuse
* Round corners of PCB
